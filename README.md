# ペンギン戦績メモ

**Faaast Penguin の画面を見て、レースの結果を自動で記録するブラウザツールです。**
遊んでいる画面を共有しておくだけで、コース・Activity・順位・タイムが記録されます。

> ファンが作った非公式ツールです。Faaast Penguin の開発・運営とは関係ありません。
> 記録はすべて自分のブラウザの中に保存され、どこにも送信されません。

---

## できること

| 機能 | 内容 |
|---|---|
| 自動記録 | コース名・Activity（1〜3・Final）・順位・タイムを、画面から読み取って記録 |
| DROP OUT | ゴール人数の上限に届かずに終わったレースも「DROP OUT」として記録 |
| 通常マッチ／カスタムマッチ | ロビーの画面から自動で見分け、記録を分けて表示 |
| NEW RECORD の切り抜き | 自己ベストを更新したレースを、Steam の録画から「レース開始〜ゴール後10秒」だけ動画として保存（画質そのまま・音声付き） |
| 戦績のまとめ | レース数・平均順位・1位の回数・表彰台率、コースごとの成績（順位・タイムの推移グラフ） |
| マッチ人数 | マッチング画面の人数を読み取り、人数帯（20〜25／26〜29／30〜35／36人〜）ごとの成績を表示 |
| 好きな試合の切り抜き | 「この試合を切り抜く」ボタンで、気になった試合を Steam の録画から保存 |
| 録画から読み込み | 録画した動画ファイルからも記録できる |
| CSV | 記録を CSV で保存・読み込み（バックアップ、別のPCへの引っ越し） |

## 使い方

### 用意するもの
- Windows の PC で遊んでいる Faaast Penguin（Steam 版）
- **Google Chrome**、**Microsoft Edge**、**Brave** のどれか（最新版）
  - **Brave を使う場合**は、最初に1回だけ次の設定をしてください（しないと、切り抜きとブラックパスの確認が使えません）
    1. アドレス欄に `brave://flags` と入力して開く
    2. 上の検索欄に `File System Access API` と入力する
    3. 出てきた項目を **Enabled** に変えて、下に出る **Relaunch**（再起動）を押す
  - それ以外のブラウザ（Firefox など）では、切り抜きとブラックパスの確認が使えません

### 記録する
1. ツールのページを開く
2. 「ライブ記録」タブで **記録開始** を押す
3. 共有する画面を選ぶ画面で、**Faaast Penguin のウィンドウ**を選ぶ
   - **ゲームをフルスクリーンで遊んでいる場合は「画面全体」を選んでください。** フルスクリーンのゲームをウィンドウとして共有すると、映像が真っ黒になって読み取れないことがあります（その時はツールに案内が出ます）
   - ゲームをウィンドウやボーダーレス（フルスクリーンウィンドウ）で遊ぶなら、ウィンドウの共有で大丈夫です
   - ブラウザのタブの共有には対応していません
4. あとは普通に遊ぶだけです。ツールのページは開いたままにしておいてください

### 通常マッチとカスタムマッチ
- ロビーに出ている「プレイモード選択」（通常マッチ）と「前回のツアー結果」（カスタムマッチ）から自動で見分けます
- 記録を始めてから一度もロビーを通っていないレースは「モード不明」になります。記録一覧の「編集」から直せます

## タイムの表示について（ブラックパス）

公式では、各コースのベストタイムを見られるのは **ブラックパスの特典** です。
公式に迷惑をかけないよう、このツールでも **ブラックパスを持っていることを確認できた人だけ** タイムを表示します。
確認できるまでもタイムは記録されていて、確認できた時点で過去の分も表示されます。

### 確認のしかた
1. Steam のバックグラウンド録画をオンにする（Steam の設定 →「ゲームの録画」）
2. ツールの「ライブ記録」タブで「Steam録画フォルダ」を選ぶ（Steam の「録画の保存場所」のフォルダ）
3. 記録開始して、ゲームのウィンドウ（フルスクリーンなら画面全体）を共有する
4. ゲームで「シーズンパス」を開き、ゴールドパスとブラックパスの両方に「OWNED」と出ている画面を表示する
5. そのまま通常マッチのロビーに戻る → Steam の録画と照合して、確認完了です（数十秒かかります）

- 確認は **シーズンごと** です。シーズンが変わったら、同じ手順でもう一度確認してください
- 照合には、ブラウザが Steam の録画（HEVC 形式）を再生できる必要があります。「ライブ記録」タブの「Steam 録画との照合」の欄に、使えるかどうかが出ます
  - Chrome：パソコンのグラフィック機能が HEVC に対応していれば使えます
  - Edge：Microsoft Store の「HEVC ビデオ拡張機能」が必要な場合があります

## NEW RECORD の自動切り抜き

1. 「ライブ記録」タブの「NEW RECORD の自動切り抜き」をオンにする
2. 「Steam録画フォルダ」と「保存先フォルダ」を選ぶ
3. 記録開始のときに、フォルダを使う許可を求められるので許可する

保存先フォルダの中に「通常マッチ」「カスタムマッチ」「モード不明」のフォルダが作られ、そこに分けて保存されます。
Steam の録画は一定時間（初期設定では120分）で消えますが、切り抜きはゴールの十数秒後に自動で行うので問題ありません。

## 好きな試合を切り抜く

- 「ライブ記録」タブの **この試合を切り抜く** を押すと、レース中ならゴールの後に、レースの合間なら直前の試合を切り抜きます
- 「記録一覧」の各試合の **切り抜き** からも切り抜けます（Steam の録画が残っている、約2時間以内の試合だけ）
- 保存先は NEW RECORD の自動切り抜きと同じです（「Steam録画フォルダ」と「保存先フォルダ」を選んでおいてください）

## マッチ人数

- マッチング画面（「プレイヤーを待っています」「まもなく開始します」）に出る人数を読み取り、そのマッチのレースすべてに付けます
- 「コース別」タブの **人数帯ごとの成績** で、どの人数帯が得意かを見られます
- マッチング画面を見る前に記録を始めたレースは、人数が空欄になります（記録一覧の「編集」で入れられます）

## 新しいワールドが来たら

- 公式のコース一覧は、**ツールの更新で自動的に追加** されます（ページを開き直すだけ）
- 更新がまだのときは、「コース別」タブの「コース一覧」→ **ワールドを追加** から、ワールド名と4つのコース名を入れて追加できます
  - 一覧に無いコースを走ったレースも、読み取った名前つきで記録されています。ワールドを追加すると、その記録もさかのぼって判別されます
  - 自分で追加したワールドは、そのブラウザにだけ保存されます

## 記録の保存について

- 記録は **そのブラウザの中** にだけ保存されます（サーバーには送られません）
- 次のような場合は記録が見えなくなるので、「記録一覧」の **CSVで保存** でときどきバックアップしてください
  - ブラウザの閲覧データ（Cookie・サイトデータ）を消した
  - シークレットウィンドウで使った
  - 別のブラウザや別のPCで開いた
- 「CSVを読み込む」で、保存した記録を戻せます

## うまく記録されないとき

- ゲームは **1920×1080（16:9）** での表示を想定しています。解像度が違っても縦横比が 16:9 なら読み取れますが、小さすぎると読み間違いが増えます
- ゲームのウィンドウの上に、別のウィンドウや通知が重ならないようにしてください
- 「ライブ記録」タブのプレビューで「読み取り範囲」をオンにすると、どこを読んでいるかが表示されます
